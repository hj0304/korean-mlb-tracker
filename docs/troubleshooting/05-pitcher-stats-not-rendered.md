# 05. 투수 성적이 안 보임 — 상세 페이지가 타격 스탯만 하드코딩

## 증상
- MiLB 선수를 추가하니 투수들(고우석·문서준 등) 상세 페이지가 "시즌 기록이 없습니다"로 표시.
- 타자는 정상.

## 원인
**데이터는 정상**(API에 ERA·WHIP·이닝·승패 다 있음). 문제는 프론트:
- `PlayerDetail`이 `season_stats`를 `group_name === "hitting"`으로만 필터하고, 표시 지표도 전부 타격(타율·홈런·OPS…)으로 **하드코딩**.
- 투수는 hitting 행이 없으니 화면이 빈다.
- 코드 주석에도 `pitching split comes in S2-08`로 **의도적으로 미뤄둔** 부분이었다.

## 진단
1. API 직접 확인 → `group_name: "pitching"` 행에 `era`, `inningsPitched`, `wins` 등 정상 존재.
2. 즉 백엔드 OK → 프론트 렌더링 누락 확정.

## 해결
`player_type`별 **`StatConfig`로 분기**(S2-08):
- 투수: ERA/WHIP/K9/BB9 슬래시 + 승·패·세이브·홀드·이닝·탈삼진 타일 + 피칭 통산/경기 표.
- 타자: 기존 유지.
- 통산·경기 표·차트가 해당 그룹만 읽도록 정리(타율 추이 차트는 타자 전용).

## 교훈
- "안 보임"이 **데이터 없음**인지 **렌더링 누락**인지부터 가른다 → API를 직접 때려보면 5초.
- 시드 데이터가 한 종류(여기선 타자)만 있을 때 짠 UI는 **다른 종류가 들어오는 순간 드러난다.** 표시 로직을 처음부터 데이터 종류별 설정(config)으로 분리해두면 확장이 쉽다.
