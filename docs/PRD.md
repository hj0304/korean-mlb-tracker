# PRD — Korean MLB Tracker

> **상태**: Draft v1.1 · **작성일**: 2026-05-19 · **갱신일**: 2026-07-07 · **오너**: (본인)

> **서비스명**: **태극기 펄럭이며** (2026-07-07 리브랜딩, Sprint 4). `Korean MLB Tracker`는
> 레포/프로젝트 식별자로 유지하고, 사용자에게 보이는 이름(사이트 타이틀, OG, README 헤더)만
> 서비스명을 쓴다.

## 1. 개요

한국인 메이저리거의 당일 경기 결과와 시즌 누적 성적을 한 화면에서 한 번에 확인할 수 있는 웹사이트가 없거나, 있어도 정보가 분산되어 있다(MLB.com은 한국인 필터가 없고, KBS/SPOTV 등 국내 매체는 기사 형태라 데이터 접근이 불편).

이 프로젝트는 **모든 한국인 MLB/MiLB 선수의 "오늘"과 "시즌"을 한 페이지에서 보여주는** 도구를 만든다.

추적 대상은 한국 국적 선수에 더해 **"명예 한국인"** — 한국 출생은 아니지만 부모가 한국 국적이라 WBC 등 국제대회에서 대한민국 대표팀으로 뛴 선수(예: 토미 에드먼) — 도 포함한다. 단, 일반 한국 선수와 **별도 그룹으로 구분**해 표시한다(`players.is_honorary`, 목록 필터 + 배지). (S2-17)

## 2. 목표 (Goals)

- **G1**: 한국인 MLB 40인 로스터 선수 전원의 당일 경기 성적을 출근/등교 시간에 30초 안에 파악할 수 있다.
- **G2**: 시즌 누적 성적(타자: AVG/OPS/HR/RBI/SB, 투수: ERA/WHIP/K/IP/W-L-SV)을 선수별로 확인할 수 있다.
- **G3**: MiLB(트리플A/더블A) 한국인 유망주의 시즌 성적도 같은 UI로 본다.
- **G4**: 모바일 환경에서 불편 없이 사용된다(개발자가 직접 출퇴근길에 사용).

## 4. 페르소나 & 핵심 사용 시나리오

### 페르소나 A — "점심 시간의 야구팬 직장인" (메인 유저, 본인 포함)
> 오전 근무를 끝내고 점심 시간, 한 화면에 모든 한국 선수들의 오늘 경기 성적을 확인한다. 

**시나리오**: 12시 식당. 휴대폰으로 사이트 접속 → 첫 화면에서 5명(또는 그 이상) 카드가 보임 → 김혜성 카드 탭 → 어제 경기 4타수 2안타 1홈런 + 시즌 OPS 0.812 확인 → 대략 10초만에 바로 확인.

### 페르소나 B — "스카우팅이 취미인 헤비 유저"
> 마이너리그까지 챙겨보는 야구 팬. 다음 한국인 메이저리거 후보가 누군지 분석한다.

**시나리오**: MiLB 탭으로 이동 → 트리플A 한국인 선수 목록 → 특정 선수 클릭 → 최근 10경기 추이 그래프 확인.

## 6. 비기능적 요구사항

| 카테고리 | 요구사항 |

| **관측 가능성** | 에러 → Sentry, 트래픽 → Vercel Analytics, ETL 실패 → GitHub Actions 알림 |

## 7. 성공 지표 (포트폴리오 관점)

이 프로젝트가 "잘 됐다"의 정의:

1. ✅ **기술적**: Lighthouse 4개 영역 평균 90점 이상
2. ✅ **운영적**: 30일 무중단 (ETL 실패 자동 알림 후 24시간 내 복구)
3. ✅ **본인 KPI**: 한 달 동안 본인이 실제로 매일 사용 (도그푸딩)
